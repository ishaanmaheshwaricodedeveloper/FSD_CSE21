# Backend Development – CSE 21

A collection of backend development assignments, classroom practice, and small projects completed as part of the CSE 21 coursework.

## Repository Overview

This repository is organized into two main sections:

- **ASSIGNMENTS/** – Assignment submissions, practical experiments, and project work.
- **CLASS WORK/** – Topic-wise code and practice completed during classroom sessions.

## Topics Covered

- Node.js fundamentals
- File System (`fs`) module
- Event module
- HTTP module and routing
- REST APIs
- Express.js and HTML pages
- Express with React
- Product REST API practice
- MongoDB CRUD operations
- Request handling

## Technologies Used

- JavaScript
- Node.js
- Express.js
- React
- MongoDB
- HTML & CSS
- Git & GitHub

## How to Run

1. Open the required project folder.
2. Install dependencies if a `package.json` is present:

   \`\`\`bash
   npm install
   \`\`\`

3. Run the project using the command specified in its package configuration or instructions.

Some programs can be executed directly using Node.js without additional dependencies.

## Purpose

This repository serves as a coursework archive and a record of backend development practice through hands-on examples, assignments, and small applications.
